# Game archives (not shipped)

Screenshots, design notes, archived versions and the unused cockpit `sfx/` folder (the cockpit game embeds its
sounds in `index.html`) moved here from `public/games/` on 2026-10-19 so they no longer ship in the production
build. The playable games remain in `public/games/<game>/index.html`; Horde's sounds stay in `public/games/horde/sfx/`.
Layout is unchanged relative to each game folder (`<game>/versions/…`).
