# Xiangqi prototype — version history

`../index.html` is always the latest. Every delivered version is kept here unchanged, so any of them can be opened directly.

| File | Date | What changed |
|---|---|---|
| `xiangqi-v1.0.html` | 2026-10-18 | First playable: full xiangqi rules (flying general, hobbled horse, elephant eye, cannon screens, stalemate loses), 9 files on pads 1–8 + side buttons, 8 of the 10 ranks on the pads with ▲ ▼ scrolling, ◀ undo, Mixer = new game, clock on the top row, wooden discs with carved characters, table props and capture effects, Web MIDI to the Launchpad MK2 with reconnect handling and a click-to-open MIDI log. |

File letters sit on the frame in the top view. |

Each file is self-contained (open in Edge or Chrome; mouse and keyboard work without a Launchpad).
